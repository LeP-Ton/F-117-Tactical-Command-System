# 修复大屏任务网络连线脱节

## 背景与目标
- 任务方块使用相对容器的百分比坐标定位，SVG 连线则使用 `1000 × 600` 逻辑坐标。
- SVG 默认保持宽高比；当大屏任务区比 `5:3` 更宽时，连线会水平留白，而任务方块继续铺满容器，导致方块与虚线端点脱节。
- 目标是在任意任务区宽高比下，让节点与连线共享同一套横纵缩放规则。

## 约束与原则
- 不修改 Campaign 节点坐标、连线数据和布局结构。
- 保持现有任务区能够随容器尺寸响应式伸缩。
- 采用最小改动修复坐标系差异。

- [x] 执行类型检查、自动化测试、生产构建与差异检查。

## 根因
- `.campaign-node` 的 `left/top` 分别按任务区实际宽度和高度计算。
- SVG 默认 `preserveAspectRatio="xMidYMid meet"`，会等比缩放并在宽屏任务区中产生水平留白。
- 因此，同一个逻辑坐标在 HTML 节点层和 SVG 层被换算成了不同的屏幕坐标。

## 代码变更
- `src/ui/CampaignMap.tsx`：关闭 SVG 的等比保持，让 `1000 × 600` 逻辑坐标分别铺满任务区宽高，与节点百分比定位完全一致。

```diff
-          <svg viewBox="0 0 1000 600" aria-label="战役节点连线">
+          <svg
+            viewBox="0 0 1000 600"
+            preserveAspectRatio="none"
+            aria-label="战役节点连线"
+          >
```
