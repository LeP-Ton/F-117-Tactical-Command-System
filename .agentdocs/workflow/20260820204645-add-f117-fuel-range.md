# 增加 F-117 燃油航程限制

## 背景与目标
- 为航线规划增加燃油约束，避免玩家无限绕飞雷达与天气区域。
- 按当前 `1000×1000` 地图比例，将满油航程设为地图两条边之和 `2000 u`。

## 约束与原则
- 燃油按实际累计飞行距离消耗，不按时间或帧首尾直线距离粗略计算。
- 剩余燃油不足当前 Tick 计划距离时，不允许飞机透支航程。
- 燃油耗尽只令当前任务失败，不像导弹命中那样直接令整个 Run 进入 `DEFEAT`。
- 任务重置必须恢复满油。
