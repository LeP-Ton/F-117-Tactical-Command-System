# 添加事件驱动的游戏音效

## 背景与目标
- 为雷达发现、警戒、锁定、导弹、打击和任务结算提供即时听觉反馈。
- 使用浏览器原生 Web Audio API 合成音效，不引入外部素材、依赖或资源加载流程。
- 提供静音和总音量控制，并正确处理循环警报生命周期。

## 约束与原则
- 音效只消费领域事件和任务状态，不修改游戏规则。
- 首次用户交互后才创建或恢复 AudioContext，以符合浏览器自动播放限制。
- Contact 高频事件必须节流，失败事件必须去重，避免声音叠加失控。
- 锁定和导弹循环音必须在暂停、脱锁、任务结束和组件卸载时停止。

## 测试用例

### TC-001 浏览器解锁
- 操作：首次点击或按键后开始任务。
- 预期：AudioContext 成功启用，后续事件可以播放。
- 是否通过：由浏览器手动验证。

### TC-002 战斗反馈
- 操作：触发 Contact、警戒升级、锁定、导弹、脱锁和投弹。
- 预期：播放对应提示，Contact 不因同帧多雷达而密集爆音。
- 是否通过：事件映射自动化测试通过；听感待浏览器手动验证。

### TC-003 循环音清理
- 操作：在锁定或导弹来袭期间暂停、脱锁或结束任务。
- 预期：循环警报立即停止。
- 是否通过：状态同步逻辑已覆盖，待浏览器手动验证。
