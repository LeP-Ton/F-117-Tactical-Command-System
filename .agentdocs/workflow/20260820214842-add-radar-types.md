# 增加真实雷达类型与分层防空

## 背景与目标
- 旧版所有雷达只有位置、范围和 ID 差异，部署名称不构成功能类型。
- 增加真正参与探测、Contact 与交战计算的雷达职责差异。

## 类型设计
- `EARLY_WARNING`：380–470 u，0.40 s 扫描，36° 波束，远程预警但精度与火控贡献较低。
- `ACQUISITION`：270–360 u，0.25 s 扫描，24° 波束，均衡搜索与目标获取。
- `FIRE_CONTROL`：180–260 u，0.16 s 扫描，12° 波束，近程高精度且火控贡献最高。

## 约束与原则
- 类型参数集中在唯一画像表，生成、Sensor、交战和 UI 不重复维护数值。
- 普通任务最少三部雷达，因此必须至少包含一部每种类型。
- 类型只改变雷达能力，不突破 Reality → Sensor → Contact → AI 信息边界。
