# 增大音量标签左侧间距

## 背景与目标
- 顶部声音开关与 `VOL / 音量` 标签之间距离偏近，两个功能区的视觉边界不够清晰。
- 单独增大标签左侧间距，不改变标签与音量滑杆之间的距离。

## 约束与原则
- 不改变音量滑杆尺寸、样式和交互。
- 不修改顶部控件的统一高度或全局间距。
- 中英文使用同一布局规则。
