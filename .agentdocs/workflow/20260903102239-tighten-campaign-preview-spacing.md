# 收紧任务预览段落间距

## 背景与目标
- 任务网络右侧预览会连续显示任务作用、情报权限与部署提示三段文字。
- 通用段落样式原先为每个段落设置 `70px` 最小高度，短文案也会占据大块空白，导致三段信息在视觉上彼此脱节。
- 本次将段落恢复为由内容自然撑高，并设置统一的紧凑间距。

## 约束与原则
- 仅调整任务预览段落布局，不修改文案、任务规则或情报权限。
- 保留预览按钮自身与说明区之间的 `18px` 间距。
- 不更新 `AGENTS.md`，因为本次不影响项目整体或核心机制认知。

## 关键风险
- 长文案仍需按侧栏宽度自然换行，不能以固定高度裁切或强制单行显示。
- 调整段落外边距时不能连带缩小预览按钮的独立分隔。

## 当前进展
- 三段预览文字均按实际内容高度占位。
- 相邻段落间距统一为 `14px`，段落不再继承浏览器默认上下外边距。
- 浏览器实测三个段落的 `min-height` 均为 `0px`，相邻视觉间距均为 `14px`；第三段换为两行时高度自然增加为 `34px`。

## 代码变更
- `src/ui/styles.css`：取消任务预览段落的固定最小高度，增加统一上间距。

```diff
-.campaign-preview p { min-height: 70px; color: #72978b; font-size: 10px; line-height: 1.7; }
+.campaign-preview p { min-height: 0; margin: 14px 0 0; color: #72978b; font-size: 10px; line-height: 1.7; }
```
