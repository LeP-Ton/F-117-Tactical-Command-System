# 统一顶部按钮与输入框高度

## 背景与目标
- 顶部工具栏的语言切换、操作说明、声音开关、行动代码输入框和初始化按钮分别依赖字体尺寸与内边距计算高度。
- 不同文字和表单控件的浏览器默认行高不同，实际高度介于 `26.5px` 至 `30px`，造成上下边缘错位。
- 本次统一所有顶部矩形按钮和行动代码文本输入框的外部高度。

## 约束与原则
- 只统一矩形交互控件的高度，不改变配色、宽度、文字大小和按钮语义。
- 音量滑杆不属于文本输入框，保持原有轨道尺寸。
- 不更新 `AGENTS.md`，因为本次不影响项目整体或核心机制认知。

## 关键风险
- 不能将尺寸规则作用于音量滑杆，否则会破坏滑杆的视觉比例。
- 固定高度后仍需保留控件原有内边距，使中英文文字都能垂直居中且不被裁切。

## 当前进展
- 顶部所有按钮与行动代码输入框统一为 `30px` 高。
- 浏览器实测五个目标控件的顶部均为 `15.5px`、底部均为 `45.5px`，边缘完全对齐。
- 音量滑杆未应用固定高度规则。

## 代码变更
- `src/ui/styles.css`：为顶部按钮及行动代码输入框设置统一的边框盒模型与固定高度。

```diff
+.topbar-controls button, .seed-control input { box-sizing: border-box; height: 30px; }
```
